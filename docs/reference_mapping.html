Correctness checkpoint 0.1.1 / result schema 2: _math.h4_status distinguishes true zero log evidence from probability underflow; summary logU3/logU4 retain diagnostic evidence. _validation.weights admits partial zeros uniformly. abf.process_dataset explicitly rejects effect_priors on P/MAF/N, retaining the fixed approx.bf.p scales. Quantitative beta prior SD is multiplied by sdY, then squared, as the pinned approx.bf.estimates code actually does (despite its parameter documentation calling the inputs variances). Counterexamples and regression tests are in upstream differences.

Locus feature 0.2.0

annotation.models contains original provider-independent models, inclusive exon union and documented transcript selection. annotation.local adapts official gffutils SQLite indexing/overlap/parent queries with local provenance and locking. locus_ld implements explicit LD validation, ID mapping and audited plot-only thinning. locus implements the five-panel layout and physical triangle; these are new visualization APIs, not ports of statistical R functions. See locus plots and the annotation/locus tests for these interfaces.
