New fixed-R measurements

These full-call measurements use pycoloc 0.2.2rc3 and prusie 0.2.3rc4, R 4.4.0 with OpenBLAS 0.3.20, coloc 6.0.3 and susieR 0.16.6. Each backend uses one numerical thread. The fixed real panel has 100 regions, 200 traits and 103–4162 SNPs per region. It consists of previously selected association windows from one disease/cell-type pairing; it is not a random sample of all loci.

Complete records and counterexamples

The per-case table (TSV, JSON), all retained repeats, summary and parameters/protocol preserve all workloads and statuses. Per-repeat rows link to separate numerical validation and separate case/backend memory measurements; those quantities are not measured inside every timing repetition. Private genotypes, association files, variant IDs and input paths are not redistributed.

  • ABF: 65/100 slower primary cases (first IDs: region02, region03, region04, region05, region07, region08, region09, region11); 0/100 higher-RSS cases (first IDs: none). Lowest speed ratio: region49, 0.541×; lowest memory ratio: region24, 2.61×. Paired memory ratio median 2.66 [Q1 2.64, Q3 2.67], range 2.61–2.7; median per-case RSS reduction 62.4%. Summed case medians: R 0.447 s, Python 0.481 s.
  • All component BFs: 0/99 slower primary cases (first IDs: none); 0/99 higher-RSS cases (first IDs: none). Lowest speed ratio: region08, 2.11×; lowest memory ratio: region48, 2.62×. Paired memory ratio median 2.67 [Q1 2.66, Q3 2.67], range 2.62–2.75; median per-case RSS reduction 62.5%. Summed case medians: R 4.1 s, Python 1.41 s.
  • Existing-fit CS pairing: 1/65 slower primary cases (first IDs: region45); 0/65 higher-RSS cases (first IDs: none). Lowest speed ratio: region45, 0.726×; lowest memory ratio: region08, 2.58×. Paired memory ratio median 2.68 [Q1 2.67, Q3 2.69], range 2.58–2.71; median per-case RSS reduction 62.7%. Summed case medians: R 0.626 s, Python 0.364 s.

An OS peak includes imports, inputs, the full return and native allocations; it is not incremental algorithm memory. BF/CS consumers load matched complete BF matrices, variant IDs, original CS/member IDs and convergence metadata, without the unused coefficient arrays of an upstream fitting workspace. Fine-mapping retains its full standard result. Runtime and memory conclusions apply to this panel and environment.

All formal calls ran sequentially in one reserved measurement window. The audit recorded 0 pressure-contaminated attempts and 0 process-failed attempts. The predeclared rule retains contaminated attempts and repeats both backends; all original records remain available. Shared-host load monitoring is best effort. The default NumPy coloc path was measured; no fresh Numba compilation or warm-JIT performance claim is made.

Reproduce a full-call comparison

The bounded comparison scripts run the full coloc_abf, coloc_bf_bf or coloc_susie API against coloc 6.0.3. Inputs are loaded before the clock; checks, preprocessing and ordinary result construction remain inside it. Each backend has one warmup and at least seven retained repeats. Small calls are batched identically. Backend order is alternated between cases; numerical library threads are fixed to one.

A separate fresh process performs one complete call per case/backend for peak process RSS in MiB. The OS high-water mark includes the interpreter, imports, loaded inputs, native allocations and the returned object. Numerical serialization happens after capture. This metric is distinct from SuSiE-RSS, the statistical summary-data model.

Report median R time / median Python time for each case and paired distributions, including slower cases, variability and convergence states. Memory ratios are reported separately; runtime gains do not imply smaller process RSS. Only measurements with a stated R version, optimized BLAS, thread count and matched inputs support a comparison with R.

Implementation scope

The stable H3 numerical reduction uses O(m) work and no m×m configuration matrix. The full API also validates, aligns and sorts SNPs and constructs pandas tables; its complexity is not described by that reduction alone. Optional Numba compiles only the H3 reduction, not input preparation or full result construction. Its first call includes compilation and must be separated from warm calls.

LD is unnecessary for ABF in either Python or R. Dense LD for upstream fine-mapping costs O(m²) storage. Plot-only LD thinning leaves analysis inputs and association tracks unchanged. See locus plots for rendering and annotation details, and agreement for numerical scope.
