Runtime and peak memory

pycoloc was timed against coloc 6.0.3 on 100 real regions and on coloc's 500-variant toy example. The measurements used pycoloc 0.2.2rc3 (with prusie 0.2.3rc4 for the fits), R 4.4.0 with OpenBLAS 0.3.20 and susieR 0.16.6, and one numerical thread in both languages. The inference code is unchanged in 0.2.2.

The regions are association windows from one GWAS and one eQTL study, chosen before these measurements, with 103–4162 variants each. They are not a random sample of loci.

The tables use regions where both calls succeeded and both fits converged; fitting itself is not timed. ABF takes a few milliseconds in either language, and pycoloc is slightly slower in 65 regions (slowest ratio 0.54×, region49). Credible-set pairing is slower only in region45 (0.73×). In the other 35 regions (34 without a credible set, one nonconverged) both return almost immediately, R in a median 0.2 ms and pycoloc in 1.1 ms; including them gives a geometric-mean speedup of 0.81×.

How the measurements were made

Each call goes through the public API (coloc_abf, coloc_bf_bf, coloc_susie and their R counterparts). Inputs are loaded before the clock starts; input checks, preprocessing and building the result tables are timed. Each backend gets one warmup and seven timed repeats; very short calls are batched in the same way for both. The order of R and Python alternates between regions, and all calls ran one after another.

Peak RSS is the operating-system high-water mark of a fresh process that makes one call. It includes the interpreter, imported libraries, the loaded inputs and the returned result, so it mostly reflects the size of the Python and R runtimes rather than the colocalisation algorithm. The default NumPy path was measured, not Numba.

The comparison scripts reproduce a single call. The complete records are available as a per-region table (JSON), all repeats, a summary and the protocol. Genotypes, association files and variant IDs from the real regions are not redistributed.

Complexity

The H3 sum uses O(m) work for m shared variants and never forms an m × m matrix. A full call also validates, aligns and sorts variants and builds pandas tables. ABF needs no LD. Fine-mapping upstream needs a dense m × m LD matrix (about 8m² bytes in float64). Thinning LD for a locus plot affects only the figure.
